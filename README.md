# מדייטים לאהבה

אפליקציית התפתחות אישית בתחום הזוגיות, מבוססת אך ורק על הספר
**"מדייטים לאהבה — דייטינג הוא חיפוש; אהבה היא בנייה"** מאת צחי חן (2026).

> אהבה לא מוצאים. בונים.

## מה זה

האפליקציה הופכת את הספר למוצר אינטראקטיבי:
- **אבחון** של 12 שאלות שמזהה איזה "נהג ישן" מנהל אותך כרגע.
- **15 כלים אינטראקטיביים** — משולש העובדה, שלוש שאלות השער, מדרג הגבולות, תחזוקת ה־20, נוהל 72 שעות, ועוד.
- **אזור למידה** של 8 תחנות המסע: מוכנות → אודישן → רעש → ניצוץ → שער → אחרי השער → בנייה → תיקון.
- **המאמן** — AI מבוסס ספר בלבד, עם 5 יכולות: ניתוח סיטואציה, ניתוח דייט, יומן, תוכנית אישית, ותרגול שיחות.
- **ערכת חירום** ו**מסך בטיחות** נגישים תמיד.

## טכנולוגיה

- Next.js 14 (App Router)
- TypeScript strict
- Tailwind CSS + RTL מלא
- Zustand + localStorage (Phase 1 — בלי backend)
- Mock AI Provider (יוחלף ב-Claude + RAG ב-Phase 2)

## פיתוח

```bash
npm install
npm run dev
```

הדפדפן יפתח ב־`http://localhost:3000`.

## מפת פיתוח (3 שלבים)

- **Phase 1 (זה הקוד הזה)** — UI מלא, כל התוכן, כל הכלים, localStorage, Mock AI.
- **Phase 2** — Supabase + Auth (Guest mode), RAG על הספר, Claude אמיתי, Memory.
- **Phase 3** — Analytics PostHog, Free/Premium gating אמיתי, פיצ'רים מתקדמים.

## מבנה התיקיות

```
src/
├── app/                Next.js routes
├── components/         UI primitives + feature components
├── content/            כל התוכן מהספר (פרקים, כלים, שאלות, נספחים)
├── services/           AI, Analytics, Entitlements — מודולרי לפי interfaces
├── store/              Zustand stores
├── types/              Types משותפים
└── lib/                Utilities (cn, scoring)
```
