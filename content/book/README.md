# בסיס הידע של "המאמן"

הקובץ `manuscript.txt` הוא **מקור האמת היחיד** של ה-AI. כל תשובה של המאמן מבוססת אך ורק עליו.

## למה זה כאן ולא בקוד?

מבנה דינמי: כדי לעדכן את הספר אין צורך לגעת בקוד. עורכים את `manuscript.txt`, מריצים:

```bash
npm run index:book
```

הסקריפט מחלק את הספר ל-chunks, מחשב embeddings (OpenAI), ושומר ב-Supabase pgvector.

## חוקי עריכה

1. כל פרק חייב להתחיל בשורה `פרק N — כותרת` או `נספח X — כותרת`.
2. השאר את הניקוד והאיות כפי שהם — ה-embeddings רגישים לאיות.
3. אל תוסיף מידע שאינו מהמחבר. הרעיון הוא לשמור על "Book-Based Only".
